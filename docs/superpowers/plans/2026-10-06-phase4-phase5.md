# Phase 4 EAR + Phase 5 MAR Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans for inline execution, or superpowers:subagent-driven-development for independent core modules. Steps use checkbox syntax. This is a plan only: no implementation or new acceptance claims yet.

**Goal:** Implement pixel-correct EAR for both anatomical eyes and project-defined inner-lip MAR, integrate them into the existing landmark preview, and verify numerical/invalid behavior plus real visual transitions.

**Architecture:** Two independent stateless extractors consume existing `LandmarkResult` and return existing `EyeFeatures`/`MouthFeatures`. The Phase 3 preview owns capture/model lifecycle, calls each extractor once per emitted frame (including no-face) and displays values/validity without changing the original image or timestamp. No generic geometry framework or Phase 7 pipeline is introduced.

**Tech Stack:** Existing Python 3.12 `.venv`, NumPy, OpenCV contrib, MediaPipe Tasks, pytest. No new dependency.

## Global constraints
- Working dataset: **34 existing verified videos / 12 subjects**. No additional download, no full-dataset processing/training, no requirement to complete acquisition45.
- Follow [roadmap Phase4/5](../../16_Development_Roadmap.md), [formulas/topology](../../06_Feature_Engineering.md), [contracts](../../15_Module_Specification.md), [test strategy](../../17_Testing_Strategy.md).
- Preserve shared dataclasses and `facial_features_v1`; do not add labels, confidence, visibility or classifier output to realtime records.
- Convert selected normalized **x/y to pixels with x*W,y*H before distances**; ignore z for these 2D measurements. Do not scale all478 points just to read6/8 points.
- Anatomical left eye `(362,385,387,263,373,380)`; right `(33,160,158,133,153,144)`. Preview is unmirrored, retains aspect ratio and original inference image.
- EAR `(d(p2,p6)+d(p3,p5))/(2*d(p1,p4))`. Left/right validity independent; mean only valid when both eyes valid.
- MAR `(d82,87+d13,14+d312,317)/(3*d78,308)`. Do not replace with outer-lip topology or another formula.
- `epsilon` from preprocessing config (currently1e-6), interpreted against the **complete pixel denominator**, not only raw horizontal distance. Equality to epsilon is invalid. Constructor accepts only finite positive non-boolean numeric epsilon.
- Missing face/points or bad geometry → NaN plus false validity; never false0. A genuinely closed mouth/eye with nonzero horizontal width may yield valid0.
- Wrong point-array schema (not numeric floating ndarray[478,3]) or nonpositive/noninteger W/H when points are present → ValueError with clear interface reason. No silent truncation/padding or topology guessing.
- Geometry validity checks only the points needed by that channel: selected x/y finite/in-frame `[0,1]`, finite pixel distances, denominator>epsilon, finite result. Invalid left eye must not erase a valid right eye. This is not a blur/occlusion/pose quality guarantee.
- No clipping ratios to0..1, calibration, blink/PERCLOS/yawn events, head pose, audio, drowsiness decisions, dataset builder or Parquet feature extraction in these phases.
- Persistent tests target consumer bugs/numeric boundaries, not exact messages, source text, default copies, GUI text or mock echoes. Hardware/model smoke remains separate from deterministic unit suite.
- Read LSP references before changing exported preview symbols; if no server is available, use bounded references search in `src/`, `scripts/`, `tests/`. Migrate every actual caller, no compatibility aliases.
- Workspace currently has no Git repository. Do not invent commits/create a repo; record verification artifacts and update existing docs after proof.

## Decisions and alternatives
**Chosen:** Two independent modules, then one integration owner edits preview. Minimal surface; Phase5 does not import Phase4 to perform geometry. Small local validation in each extractor is acceptable; no generic ratios framework.

**Alternative:** Shared geometry abstraction plus extractor registry. Reject for this scope: extra interfaces and indirection for two short formulas; prematurely anticipates Phase6/7. EAR and MAR cores can run in parallel, but preview changes must be integrated by one owner. Recommended execution order is EAR → EAR preview/QC → MAR → combined preview/QC for clear checkpoints.

- [ ] **4. Implement extractor.** Use exactly this calculation/control structure, with schema checks as specified above:
```python
import math
from numbers import Integral, Real
import numpy as np
from src.contracts import EyeFeatures, LandmarkResult

LEFT_EYE = (362,385,387,263,373,380)
RIGHT_EYE = (33,160,158,133,153,144)

class EyeFeatureExtractor:
    def __init__(self, epsilon: float):
        if isinstance(epsilon, bool) or not isinstance(epsilon, Real) or not math.isfinite(epsilon) or epsilon <= 0:
            raise ValueError("epsilon must be finite and positive")
        self.epsilon = float(epsilon)

    def extract(self, result: LandmarkResult) -> EyeFeatures:
        if not result.face_detected or result.points is None:
            return EyeFeatures(math.nan, math.nan, math.nan, False, False)
        points, size = result.points, result.image_size
        if not isinstance(points, np.ndarray) or points.shape != (478,3) or not np.issubdtype(points.dtype, np.floating):
            raise ValueError("Expected floating landmark array [478,3]")
        if not isinstance(size, tuple) or len(size) != 2 or any(isinstance(v, bool) or not isinstance(v, Integral) or v <= 0 for v in size):
            raise ValueError("image_size must be positive integer (W,H)")
        values = []
        for ids in (LEFT_EYE, RIGHT_EYE):
            xy = np.asarray(result.points[list(ids), :2], dtype=np.float64)
            if not np.isfinite(xy).all() or np.any(xy < 0) or np.any(xy > 1):
                values.append(math.nan)
                continue
            xy *= result.image_size
            denominator = 2.0 * np.linalg.norm(xy[0] - xy[3])
            numerator = np.linalg.norm(xy[1] - xy[5]) + np.linalg.norm(xy[2] - xy[4])
            ratio = numerator / denominator if math.isfinite(denominator) and math.isfinite(numerator) and denominator > self.epsilon else math.nan
            values.append(float(ratio) if math.isfinite(ratio) else math.nan)
        left, right = values
        left_valid, right_valid = math.isfinite(left), math.isfinite(right)
        mean = (left + right) / 2 if left_valid and right_valid else math.nan
        return EyeFeatures(left, right, mean, left_valid, right_valid)
```
The code shows complete constructor/schema/size guards. Selected coordinates are copied before pixel scaling; original478-point array remains unchanged. Do not convert invalid to zero.

```python
from src.contracts import EyeFeatures, MouthFeatures

def format_measurement(value: float, valid: bool) -> str:
    return f"{value:.3f}" if valid and math.isfinite(value) else "N/A"

def draw_overlay(image_bgr: np.ndarray, result: LandmarkResult, *,
                 eyes: EyeFeatures | None = None, mouth: MouthFeatures | None = None) -> np.ndarray:
    image = image_bgr.copy()
    width, height = result.image_size
    if result.points is not None and result.face_detected:
        pixels = np.rint(result.points[:, :2] * (width,height)).astype(np.int32)
        for x,y in pixels:
            if 0 <= x < width and 0 <= y < height:
                cv2.circle(image,(int(x),int(y)),1,(80,220,80),-1)
        for ids,color in ((LEFT_EYE,(255,180,0)),(RIGHT_EYE,(0,180,255))):
            cv2.polylines(image,[pixels[list(ids)]],True,color,2)
        message = f"478 landmarks | {result.timestamp_ms} ms"
    else:
        message = f"NO VALID FACE | {result.timestamp_ms} ms"
    rows = [message,"L(anatomical): cyan | R: orange | NOT mirrored"]
    if eyes is not None:
        left = format_measurement(eyes.ear_left,eyes.left_eye_valid)
        right = format_measurement(eyes.ear_right,eyes.right_eye_valid)
        mean = format_measurement(eyes.ear_mean,eyes.left_eye_valid and eyes.right_eye_valid)
        rows.append(f"EAR L:{left} R:{right} mean:{mean}")
    if mouth is not None:
        rows.append(f"MAR:{format_measurement(mouth.mar,mouth.mouth_valid)}")
    for i,row in enumerate(rows):
        cv2.putText(image,row,(8,24+21*i),cv2.FONT_HERSHEY_SIMPLEX,0.5 if i == 0 else 0.4,(255,255,255),1,cv2.LINE_AA)
    return image
```

```python
def new_geometry_summary():
    return {"scheduled_frames":0,"valid_frames":0,"invalid_frames":0,
            "min":None,"max":None,"sum":0.0}

def update_geometry_summary(summary,value,valid):
    summary["scheduled_frames"] += 1
    if not valid or not math.isfinite(value):
        summary["invalid_frames"] += 1
        return
    summary["valid_frames"] += 1
    summary["sum"] += float(value)
    summary["min"] = float(value) if summary["min"] is None else min(summary["min"],float(value))
    summary["max"] = float(value) if summary["max"] is None else max(summary["max"],float(value))

def export_geometry_summary(summary):
    result = {key:value for key,value in summary.items() if key != "sum"}
    result["mean"] = summary["sum"]/summary["valid_frames"] if summary["valid_frames"] else None
    return result
```

```python
import math
from numbers import Integral, Real
import numpy as np
from src.contracts import LandmarkResult, MouthFeatures

MOUTH_HORIZONTAL = (78,308)
MOUTH_VERTICAL = ((82,87),(13,14),(312,317))

class MouthFeatureExtractor:
    def __init__(self, epsilon: float):
        if isinstance(epsilon, bool) or not isinstance(epsilon, Real) or not math.isfinite(epsilon) or epsilon <= 0:
            raise ValueError("epsilon must be finite and positive")
        self.epsilon = float(epsilon)

    def extract(self, result: LandmarkResult) -> MouthFeatures:
        if not result.face_detected or result.points is None:
            return MouthFeatures(math.nan, False)
        points, size = result.points, result.image_size
        if not isinstance(points, np.ndarray) or points.shape != (478,3) or not np.issubdtype(points.dtype, np.floating):
            raise ValueError("Expected floating landmark array [478,3]")
        if not isinstance(size, tuple) or len(size) != 2 or any(isinstance(v, bool) or not isinstance(v, Integral) or v <= 0 for v in size):
            raise ValueError("image_size must be positive integer (W,H)")
        ids = MOUTH_HORIZONTAL + tuple(i for pair in MOUTH_VERTICAL for i in pair)
        xy = np.asarray(result.points[list(ids),:2], dtype=np.float64)
        if not np.isfinite(xy).all() or np.any(xy < 0) or np.any(xy > 1):
            return MouthFeatures(math.nan, False)
        xy *= result.image_size
        denominator = 3.0 * np.linalg.norm(xy[0] - xy[1])
        numerator = sum(np.linalg.norm(xy[a] - xy[b]) for a,b in ((2,3),(4,5),(6,7)))
        value = numerator / denominator if math.isfinite(denominator) and math.isfinite(numerator) and denominator > self.epsilon else math.nan
        return MouthFeatures(float(value) if math.isfinite(value) else math.nan,
                             math.isfinite(value))
```
This independent module includes complete guards, without importing eye.py. Epsilon is checked on3*width; invalid geometry returns a sample, bad schema is an interface error.
