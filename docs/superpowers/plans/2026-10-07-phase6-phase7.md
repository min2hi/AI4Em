## Decisions, alternatives and necessary specification corrections

### 1. Pose basis: fix the reflection before implementation
The current06 example diag(1,-1,1) has determinant-1. Its face axes x=image-right/y=down/z=toward viewer are left-handed; they cannot be the neutral basis of an SO(3) rotation in OpenCV camera coordinates. Do not fit this reflection then conceal a180-degree result with a constant subtraction.

**Chosen convention:** load canonical vertices by zero-based vertex ID (only lines beginning `v ` count), then multiply selected XYZ by **D=diag(1,-1,-1)**. This is a proper rotation, determinant+1. The resulting neutral object basis is x=image-right, y=down, z=away from camera; the anatomical forward vector is `(0,0,-1)`. Neutral ideal frontal projection has R=I, not a180-degree offset.

Keep human-readable signs requested by the project: pitch+ = down, yaw+ = image-right, roll+ = clockwise on the unmirrored image. Consequently define **R=Rz(roll) Ry(-yaw_display) Rx(pitch)**. Raw OpenCV Euler yaw from R has the opposite sign to displayed yaw. Update06's basis/Euler sentence and15's pose convention in Task1; don't leave two contradictory definitions. Mirroring only a future UI must not alter inference angles.

Planning arithmetic check already performed on the six actual canonical coordinates with cv2.projectPoints/solvePnP ITERATIVE: zero and isolated ±10-degree pitch/yaw/roll recovered within1 degree; D determinant+1; positive pitch moves the forward vector down, positive displayed yaw image-right. No production pose module exists yet.

### 2. Intrinsics
**Recommended:** calibrated K/distortion when supplied, otherwise the explicitly disclosed approximate model fx=fy=max(W,H), cx=W/2, cy=H/2, distortion0. Approximate flag lives in preview/run/video metadata, not a fake new PoseFeatures field. Recompute/scale K for actual image size, including nonuniform resize. This supports the existing clips without pretending to have camera calibration.

Alternative strict calibrated-only: best metric trust, but would block current clips/camera until calibration is available. Alternative MediaPipe transform matrix instead of solvePnP: rejects this plan's explicit six-point/reprojection acceptance and changes existing detector outputs. Use neither by default.

### 3. Quality gates are raw, not calibrated deltas
Current config max_yaw_delta_deg35/max_pitch_delta_deg25 describe a future calibrated signal. Phase7 has no pose baseline. Introduce separately named **quality.max_abs_yaw_deg=35 / max_abs_pitch_deg=25**, explicitly approximate-camera raw gates; preserve the delta keys for their future documented use. Do not silently take a median of initial frames or pretend baseline0 is personal calibration.

Chosen conservative policy: poor light/blur/invalid face ROI invalidates all channels; missing/invalid or excessively oblique pose invalidates eyes **and mouth**, while a geometrically valid oblique pose remains available as pose. This explicitly extends06's eye-only pose gate to the mouth: Phase5 observed high MAR from profile views with no actual opening. Record this policy change in06/15, not a ratio cap. Manual eyes_occluded disables only eyes; no automatic sunglasses detector. Tune/freeze actual optical thresholds from visually checked image-quality samples, never class labels/model metrics.

### 4. Snapshot validation differs from acquisition completeness
src/datasets/manifest.py:132–134 requires all0/5/10 per subject. Calling it unchanged will reject the agreed34-video snapshot. Add **validate_working_manifest** beside the existing validator, reusing MANIFEST_COLUMNS/SOURCE_LABELS and their identity rules; it accepts partial class coverage and retained error rows, but not ambiguous IDs/labels/folds. Keep validate_manifest and Phase2's full acquisition gate strict; no default relaxation or renamed acquisition success.

    (-4.445859,2.663991,3.173422), (4.445859,2.663991,3.173422),

@pytest.fixture
def temporary_canonical(tmp_path):
    vertices = np.zeros((468,3),dtype=float)
    vertices[list(POSE_IDS)] = CANONICAL_SIX
    lines = ['# fixture: only v records count']
    for x,y,z in vertices:
        lines.extend((f'v {x} {y} {z}','vt 0 0','vn 0 0 1'))
    path = tmp_path/'canonical.obj'
    path.write_text('\n'.join(lines)+'\n',encoding='utf-8')

def signed_rotation(pitch, yaw_display, roll):
    p,y,r = np.deg2rad((pitch,-yaw_display,roll))
    cp,sp,cy,sy,cr,sr = np.cos(p),np.sin(p),np.cos(y),np.sin(y),np.cos(r),np.sin(r)
    rx = np.array([[1,0,0],[0,cp,-sp],[0,sp,cp]])
    ry = np.array([[cy,0,sy],[0,1,0],[-sy,0,cy]])
    rz = np.array([[cr,-sr,0],[sr,cr,0],[0,0,1]])
    return rz @ ry @ rx

def projected_result(angles, size=(640,480), K=None):
    w,h = size
    if K is None:
        K = np.array([[800.,0,w/2],[0,800.,h/2],[0,0,1]])
    rv,_ = cv2.Rodrigues(signed_rotation(*angles))
    xy,_ = cv2.projectPoints(OBJECT_SIX,rv,np.array([0.,0.,60.]),K,np.zeros(5))
    points = np.zeros((478,3),np.float32)
    points[list(POSE_IDS),:2] = xy.reshape(6,2) / (w,h)
    return LandmarkResult(points,0,True,size)

def scaled_intrinsics(reference_K, reference_size, image_size):
    sx = image_size[0] / reference_size[0]
    sy = image_size[1] / reference_size[1]
    return np.diag((sx,sy,1.0)) @ reference_K

def displayed_angles(R, epsilon):
    cy = math.hypot(float(R[0,0]),float(R[1,0]))
    if cy <= epsilon:
        return None
    pitch = math.atan2(float(R[2,1]),float(R[2,2]))
    raw_yaw = math.atan2(-float(R[2,0]),cy)
    roll = math.atan2(float(R[1,0]),float(R[0,0]))
    return tuple((float(a)+180)%360-180 for a in np.rad2deg((pitch,-raw_yaw,roll)))

Metric calculation insertion:
```python
from numbers import Integral
import cv2
import numpy as np

def measure_quality(image_bgr, result):
    names = ('brightness','blur_variance','left_eye_width_ratio','right_eye_width_ratio')
    metrics = dict.fromkeys(names)
    size = result.image_size
    if not isinstance(size,tuple) or len(size)!=2 or any(
        isinstance(v,bool) or not isinstance(v,Integral) or v<=0 for v in size):
        raise ValueError('Expected positive integer image_size (W,H)')
    w,h = size
    if not isinstance(image_bgr,np.ndarray) or image_bgr.dtype != np.uint8 or image_bgr.shape != (h,w,3):
        raise ValueError('Expected BGR uint8 image matching image_size')
    if not result.face_detected or result.points is None:
        return metrics
    points = result.points
    if not isinstance(points,np.ndarray) or points.shape != (478,3) or not np.issubdtype(points.dtype,np.floating):
        raise ValueError('Expected floating landmark array [478,3]')
    bounds = np.asarray(points[[234,454,10,152],:2],dtype=np.float64)
    if not np.isfinite(bounds).all() or np.any(bounds<0) or np.any(bounds>1):
        return metrics
    bounds *= (w,h)
    x1,y1 = np.floor(bounds.min(axis=0)).astype(int)
    x2,y2 = np.ceil(bounds.max(axis=0)).astype(int)
    if x2<=x1 or y2<=y1:
        return metrics
    gray = cv2.cvtColor(image_bgr[y1:y2,x1:x2],cv2.COLOR_BGR2GRAY)
    scale = 256 / max(gray.shape)
    reference = cv2.resize(gray,(max(1,round(gray.shape[1]*scale)),
                                max(1,round(gray.shape[0]*scale))),interpolation=cv2.INTER_AREA)
    metrics['brightness'] = float(reference.mean())
    metrics['blur_variance'] = float(cv2.Laplacian(reference,cv2.CV_64F).var())
    for key,ids in (('left_eye_width_ratio',(362,263)),('right_eye_width_ratio',(33,133))):
        xy = np.asarray(points[list(ids),:2],dtype=np.float64)
        if np.isfinite(xy).all() and np.all(xy>=0) and np.all(xy<=1):
            xy *= (w,h)
            metrics[key] = float(np.linalg.norm(xy[0]-xy[1]))/(x2-x1)
    return metrics
```
