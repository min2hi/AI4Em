# Phase8 Working Snapshot Implementation Plan

> **For agentic workers:** Use subagent-driven-development for independent snapshot and audit slices; the controller owns native execution, integration and verification.

**Goal:** Process and account for all 34 verified working UTA videos / 12 subjects, preserving raw sources and frozen Phase7 quality policy.

**Architecture:** Reuse FeatureDatasetBuilder unchanged. Freeze a byte-identical source manifest and raw YAML plus the resolved builder signature and source/program hashes before extraction. A sequential snapshot runner checkpoints the per-video report; an independent audit reopens every complete pair and generates frame-weighted video/class/subject coverage and a separate extraction-status manifest. Metadata remains the existing last-published commit marker.

**Tech Stack:** Python 3.12, existing MediaPipe/OpenCV pipeline, pandas/PyArrow, pytest, Windows.

## Shared Interface
`runs/phase8/snapshot/manifest.parquet`: byte-identical frozen source manifest.
`runs/phase8/snapshot/preprocessing.yaml`: byte-identical config (paths resolve from project root).
`runs/phase8/snapshot/snapshot.json`: strict JSON with schema_version='working_snapshot_v1', created_at_utc, original_manifest_path, manifest_file_sha256, working_manifest_sha256, config_file_sha256, signature (FeatureDatasetBuilder._signature), source_root, output_dir, working_snapshot_count, subject_count, acquisition_planned_count=45, missing_acquisition_video_ids, sources (original full manifest rows), extraction_program_sha256 (path to hash mapping), snapshot_sha256 = builder._hash_json(all other fields).
`run_snapshot(config_path: Path, manifest_path: Path, run_dir: Path, output_dir: Path) -> dict`: consumes/creates and verifies freeze; per-video builder.build on full frozen manifest with one selected video ID; records elapsed_seconds per item; report.json checkpoints all frozen IDs (pending until attempted), then completed/cached/failed. No manifest/source mutation or weakened cache. `--run-dir`, `--config`, `--manifest`, `--output-dir` in scripts.process_snapshot.
`audit_snapshot(config_path: Path, manifest_path: Path, output_dir: Path, snapshot: dict, extraction_report: dict) -> dict`: src/preprocessing/audit.py; audit never extracts/replaces source/output pairs; all members produce complete or explicit failed audit rows, failed extraction not relabeled as complete. CLI scripts.audit_features takes --run-dir, --output-dir, --status-manifest. It loads frozen files, writes audit.json / coverage.csv and status manifest.
